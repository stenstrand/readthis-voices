# readthis-voices

Voice archives for the ReadThis app (assets only, no code).

The files in the `voices-v1` release are byte-identical copies of Piper voice packs published by the
[sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx/releases/tag/tts-models) project. They are copied unmodified, so the
upstream file names and checksums apply. `SHA256SUMS` lists the expected checksum of each file.

Download URL pattern: `https://github.com/stenstrand/readthis-voices/releases/download/voices-v1/<file>`

Only voices whose licence allows redistribution are mirrored. The licence and attribution of each voice is in
[LICENSES.md](LICENSES.md). Each archive also carries its own model card or README with the licence text from its author.
